## 최종본 선정 기준

7차시 하단 「파일만 모아둠」의 PRF 코드·연도별 결과, S-curve 코드·결과, 520 통합 시트, V2 백테스트 코드·CSV를 우선했습니다. 동일 첨부의 중복은 제거했습니다. S-curve는 같은 이름의 여러 첨부가 있어 **하단 파일 모음에 있는 버전**을 사용했습니다.

`학술제시트_517.xlsx`와 PRF 증가율 입력은 최종 코드의 실제 의존성이므로 함께 포함했습니다. 초기 511·0516 시트처럼 최종 실행에 직접 필요하지 않은 중간 버전은 본 저장소에 중복 수록하지 않았습니다. 전체 내려받기 기록 대신 공개용 [파일 출처 목록](file_manifest.json)에 선정된 파일만 기재했습니다.
